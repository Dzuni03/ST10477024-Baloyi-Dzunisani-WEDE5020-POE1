# ST10477024-Baloyi-Dzunisani-WEDE5020-POE1
I have created a website about the NGO SHOUT SA. It is about giving children opportunities to be the best version of themselves academically and they do ask the society to help contribute. 
This project involves me designing and developing a website for an NGO called SHOUT SA to improve it's online appearance. The website will show the about, enquiries, index, contact details and what service they provide. 
SHOUT has the information and links required but the information is scattered making it difficult to read. The new website will have information all together and highlights what good they do in the community they work in. 
The website should have a homepage where it shows the vision and mission statement and also an about us explaining the organisation.
